# Laravel Task Manager

A simple and ready-to-run Task Management CRUD application built with Laravel.

This project was created to demonstrate understanding of Laravel's core architecture, including MVC, Routing, Blade Templates, Eloquent ORM, Database Migrations, Validation, and Resource Controllers.

---

## Features

- Create tasks
- View all tasks
- View individual task details
- Edit tasks
- Delete tasks
- Mark tasks as completed/pending
- Form validation
- Success messages
- Responsive UI
- SQLite database
- Laravel Resource Routing
- Eloquent ORM
